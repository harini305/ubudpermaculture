# Ubud Permaculture — website (Phase 2 frontend)

Next.js App Router (JavaScript), React, GSAP + ScrollTrigger, CSS Modules. Frontend only: no backend, forms or bookings are processed by this site. Bookings go to SimplyBook; enquiries open a draft in WhatsApp or the visitor's email app.

Content comes from the Phase 1 audit in `docs/source-audit/` (do not edit those files).

## Commands

```bash
npm install
npm run dev      # local development
npm run build    # production build (all routes are statically generated)
npm start        # serve the production build
```

## Content & assets

| Path | What it is |
|---|---|
| `lib/site.js` | Verified contact details, nav, booking links |
| `lib/services.js` | The 12 SimplyBook services with verified prices |
| `lib/testimonials.js` | Testimonials (dates intentionally omitted, see audit Q8) |
| `data/posts.json` | 21 blog articles, generated by `npm run content` (`scripts/extract-posts.mjs`) |
| `data/images.json` | Manifest of resized photos in `public/images` |
| `public/video/farm-hero-720.mp4` | Hero video re-encoded to 720p H.264, 2.8 MB (original 22.3 MB) |

Images are pre-sized locally from the untouched originals with `python scripts/build-images.py` (needs Pillow with AVIF support): AVIF at 480/960/1600 px (portrait photos capped at 1200 px) plus one 800 px WebP fallback per photo for older browsers and link previews. `python scripts/prune-images.py` removes derivatives no page uses. Next.js image optimisation is disabled (`images.unoptimized`) to stay within the Vercel Hobby plan.

The original full-size uploads (`docs/source-audit/original-assets/`) and audit screenshots are kept locally and are not in the repository; the build scripts need the originals only when regenerating images. `.vercelignore` keeps `docs/` and `scripts/` out of deployments.

## Environment

`NEXT_PUBLIC_SITE_URL` sets the absolute base URL used for Open Graph images, the sitemap and robots.txt. It is not set, because the production domain has not been confirmed.
